# Historical 2026.03 input baseline

These files are unchanged copies of the manifests preceding the September 2026
toolchain migration. They bind the historical PASS results in
`verification-results.json` to their original extraction and source hashes.
They are not evidence of replay with the September tools. Paths in these
manifests are relative to the original EasyCrypt project directory, not here.
The generated source contents are available in repository commit
`f836bf6f0e8e2107f1e5f839facf63a3e66fa356`.
