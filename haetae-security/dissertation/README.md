# HAETAE provable-security dissertation

This folder mirrors the chapter-based structure used by
`haetae-ntt-verify/dissertation`.

Build, if a LaTeX distribution is installed:

```sh
make
```

Main structure:

- `main.tex` - master document and preamble.
- `chapters/` - title page, front matter, twelve chapters, and manifest appendix.
- `bibliography/refs.bib` - bibliography.
- `figures/` - reserved for diagrams.
- `record.md` - structural record and proof-scope notes.

The dissertation documents the EasyCrypt proof surface under `../provable-security/`.
