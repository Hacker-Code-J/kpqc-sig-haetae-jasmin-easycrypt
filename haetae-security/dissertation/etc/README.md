# Supplemental dissertation material

This folder stores material that is valuable for traceability but too bulky or
too mechanical for the main dissertation narrative.

## Archived files

- `app_individual_easycrypt_correspondence.tex`: exhaustive generated symbolic
  correspondence for extracted EasyCrypt declaration headers. It is retained as
  audit material, but it was removed from the main dissertation because many
  entries are necessarily templated and less persuasive than curated proof-object
  analysis.

## Editorial policy

Main dissertation chapters should contain mathematical exposition, theorem
statements, proof ledgers, trust-boundary analysis, and selected EasyCrypt case
studies. Generated catalogs and exhaustive indexes belong here unless they are
needed directly for the argument in the main text.
