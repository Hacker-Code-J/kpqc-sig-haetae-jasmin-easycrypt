memory conditions, within the following scope.

\begin{itemize}
  \item \identifier{RawApiAddressBridge} proves round trips between canonical
        integer addresses and \identifier{W64} addresses.
  \item \identifier{keypair_raw_api_exports_matching_prefixes} proves equality of
        the first 992 external VK/SK bytes after actual raw KeyGen's two sequential exports.
  \item Exact Sign/Verify traces, \(accept\Rightarrow tail\), and accepted hash-input
        binding expose actual caller control and hash arguments.
  \item Actual Sign's signature/siglen outputs preserve explicitly disjoint
        VK/SK/pre/message regions and retain KeyGen's external key prefix.
  \item Actual generated hashes are compared using only byte equality on the
        VK/pre/message read regions, instead of whole-memory equality.
  \item Executing actual raw Sign followed by cryptolab Verify corresponds exactly
        to sequential execution of the two traces, including results and final memory.
\end{itemize}

\identifier{raw_api_region_reaches_mu_zero_loss} converts these actual
external-memory facts and Sign import into \identifier{sk_memory_prefix}. This
path does not use the constructed \identifier{stores} of \cref{thm:memory-witness}.

\subsection{Frozen security gate: product/replay for stored \texorpdfstring{\(\mu\)}{mu}}

The former \claim{OBL-API-KEY-MEMORY-RAW} was decomposed in Week~5 because it was
an unconditional statement stronger than the implementation's early-reject
control flow. Since Week~6, the direct remaining obligation has narrowed to one
semantic edge.

\begin{obligation}[\claim{OBL-DIRECT-OBSERVED-MU}]
After sequential execution of the actual raw Sign trace and a successful
cryptolab Verify trace, directly conclude
\[
  \operatorname{MuPrefix}_{32}
  (\mu_{S,\mathrm{trace}},\mu_{V,\mathrm{trace}})
\]
where the two terms are respectively
\identifier{SignRawApiMuTrace.observed_mu} and
\identifier{VerifyCryptolabMuTrace.observed_mu}. A justified product/replay rule
is needed to transport the pRHL theorem for generated hash returns to the ghost
fields of the two already completed traces.
\end{obligation}

\cref{thm:sign-output-frame}, \cref{thm:region-local-mu}, and the actual sequential
trace already provide frame, locality, control, and input binding. However, the
signing continuation after the Sign hash differs from the challenge/compare
continuation after the Verify hash, so one continuation cannot be discarded
without the still-open signing losslessness result. Week~7 rejected additional
observation wrappers, preconditions that repeat the goal, and SHAKE locality
axioms, and froze \claim{OBL-MU-PRODUCT-REPLAY} as an explicit
\statusdeferred{} paper boundary. Thus this lane does not record
\(\delta_{\mu,\mathrm{raw\_api\_accept}}=0\), and no further wrappers are stacked
on the same seam.

\subsection{Recently closed gates: actual rANS core and production full HBZ}

Weeks~7--11 successively closed the canonical signature prefix, HBZ leaves/tables,
pure byte traces, actual suffix copy and harness control, and actual encoder
successful-suffix refinement. Week~12 closed
\claim{OBL-RANS-DECODE-REFINEMENT} as exact-trace partial correctness. Week~13
composed these three results inside \identifier{Mode2RansActualHarness.run},
closing \claim{OBL-RANS-CORE-INVERSE} as success-conditioned Hoare partial
correctness. Week~14 composed actual full-HBZ prepare/apply with this core inverse
and transported it exactly to the production SignaturePack/Unpack boundary,
closing \claim{OBL-SIG-HBZ-ENCODE-DECODE} at the same strength of partial correctness.

The premises of \identifier{actual_rans_encode_copy_decode_inverse} are only
initial argument binding and \identifier{mode2_hbz_symbol_stream}. If the encoder
actually fails, neither copy nor decoder runs, and the initial decoder array/state
is retained. If the encoder succeeds, the full Week~12 exact-trace input is
constructed from the actual copied segment, yielding
\[
\begin{aligned}
  bad_{\mathrm{dec}}&=0,&
  off_{\mathrm{dec}}&=\mathsf{encoded\_size},\\
  decoded[0..1024)&=expected[0..1024),&
  decoded[1024..2048)&=decoded_0[1024..2048)
\end{aligned}
\]
The copied trace, pointwise decoder reads, decoder success, and output equality
are not preconditions. \identifier{encoder_success_size_word_bridge} also derives
non-wrapping W64 size subtraction from the actual success bounds, so no arbitrary
integer-buffer witness is assumed.

\identifier{signature_pack_unpack_hbz_full_actual_exact} exactly matches the
return tuples and \identifier{decoder_ran} of the production harness and focused
full-HBZ harness. Its Hoare corollary
\identifier{signature_pack_unpack_hbz_full_inverse_mode2} concludes zero-size
failure or nonzero-size success from canonical HBZ alone. The success branch gives
(4\le size\le1024), (bad=0), 1024-coefficient recovery, coefficient/encoded tail
frames, and the actual prepare-symbol trace. Neither encoder success nor the
decoder result is a premise.

\begin{verified}[\claim{OBL-RANS-ACTUAL-SUCCESS-WITNESS}]
Week~15's \identifier{actual_rans_encode_all_six_success} proves that, on the
all-6 symbol stream produced by actual prepare, a terminating actual encoder
returns \(bad=0\), \(0\le off\le1020\), \(4\le size\le1024\), and the exact
trace/frame. \identifier{signature_pack_unpack_hbz_zero_success_mode2} lifts this
to the production pack/unpack round trip for fixed all-zero HBZ. This fixed-input
Hoare obligation is \statusproved{} because success, size, and trace are not premises.
\end{verified}

The Week~15 verdict was \identifier{GO-WITNESS}, not
\identifier{GO-WITNESS-LOSSLESS}. Termination, losslessness, probability-1 success
of the fixed-input execution, and success for general canonical inputs remain
separate. The subsequent one-week minimum paper scope superseded the original
(h)-codec recommendation, so \claim{OBL-SIG-H-ENCODE-DECODE} is currently
\statusdeferred.

\subsection{KeyGen gate: from frozen STOP-KG-NTT to current STOP-KG-AVEC-QJ}

\identifier{_keypair_finalize_m23} in a transparent two-call harness.

the snapshot mod-\(2q\) zero equality. This proves KG-2-style coefficient
decomposition and the adjusted \(s_2\) component of KG-4, but not the full paper

\begin{boundary}[\claim{STOP-KG-NTT} at paper freeze]
Connecting the full-NTT--pointwise-product--inverse-NTT result represented by
\identifier{KeygenM23ArithmeticSpec.output_row} to the security model's row-wise
polynomial product
\[
  \sum_{\mathrm{col}}
  A_{\mathrm{gen}}[\mathrm{row},\mathrm{col}]
  s_{\mathrm{gen}}[\mathrm{col}]
\]
required an odd-root orthogonality/full-NTT convolution theorem and an
\identifier{Rq.poly}--security-list adapter. Neither was present at the frozen
82-target boundary, so that claim matrix does not establish faithful KG-1, KG-3,
full KG-4, or \(As=qj\pmod{2q}\).
\end{boundary}

Post-freeze work closed \identifier{rq_mul_coeff_foldr_to_bigi}, full-NTT spectral
action, general/mode-2 row products, and the Rq--HAETAE coefficient-representation
adapter. Subsequently, the actual mode-2 sampler's nonces 515/516, SHAKE128 framing,
little-endian parsing, and rejection semantics were transported to paper \(a\),
and a separate paper \(qj\) correction was composed with the existing snapshot equality.

\begin{boundary}[Current \claim{STOP-KG-AVEC-QJ}]
The existing security model's \identifier{public_rounding_vector_seed} is a
synthetic generator based on tag 401. It equals neither the actual sampler nor
paper \(qj\), and \identifier{security_named_qj_is_not_paper_qj} proves
\(401\ne64513\) at row~0 coefficient~0. The actual first nonce-515 coefficient
for an all-zero raw seed is also 44985, so this identity cannot be assumed.
\claim{OBL-KG-SECURITY-EXPANDVECA-SEMANTICS}, replacing/refining the security model
with actual ExpandVecA semantics, must precede promotion of KG claims.
\end{boundary}

Thus the frozen \claim{OBL-MINCORE-KEYGEN} status remains \statuspartial{} for
KG-2/finalization. The current auxiliary frontier also does not promote full
KG-1--KG-4. The frozen MINCORE Sign verdict is
\identifier{STOP-SIGN-CHAL-MODE2}. The frozen MINCORE Verify verdict is
\identifier{STOP-VERIFY-MATRIX-CRT}, and restricted composition is
\statusspecified. Verify's pure NTT foundation was closed post-freeze, but the
actual procedure leaves
\identifier{verify_matrix_ntt_acc_}\allowbreak
\identifier{mode2_cols4_correct} and
\identifier{verify_crt_freeze_mode2_word_exact} remain.

\subsection{Separate functional-correctness path}

\claim{OBL-SIGN-OUTPUT-TAIL-REACH} is a \statuspartial{} obligation stating that
legitimate Sign outputs pass Verify's unpack/norm early-reject gates. The signature
prefix inverse is closed, but the full suffix and subsequent gates remain open.
This is neither the converse nor a consequence of \cref{thm:verify-accept-tail},
which proves tail reachability for successful Verify executions. It requires the
full pack/unpack inverse, norm, hint, response, and arithmetic correctness.
\claim{OBL-SIGN-VERIFY-CORRECTNESS}, combining this with full challenge equality,
is currently \statusblocked. This functional path is not inserted as a hidden
premise of the accepted-forgery security path.

\subsection{Next gates: context and the full challenge transcript}

The raw/internal and public-context paths actually differ in the implementation.
Sign uses \identifier{_sf_prepare_pre_raw} and \identifier{_sf_mu_preptr}, while
Verify selects the context branch using the most significant bit of
\identifier{prelen}. The following must be shown.

\begin{enumerate}
  \item \(ctxlen\le255\) and correctness of length encoding;
  \item Both sides absorb exactly \(ctxlen\text{-byte}\Vert ctx\) in the same order;
  \item Caller memory supplies the pointer/length premises for both procedures.
\end{enumerate}

Next, \claim{OBL-HIGH-LSB-PACK} must show equality of the packed bytes of
\(\operatorname{HighBits}_h,\operatorname{LSB}\) produced by Sign and Verify.
Composing this result with the existing \identifier{challenge_input_eq_components}
gives equality of the full challenge input lists. Only then can the actual full
call, including FIPS202 domain/padding/squeeze and the binary challenge sampler,
be connected to a paper ROM query.

\subsection{Dependency-based work order}

The following order best matches the current code.

\begin{enumerate}
  \item Retain the product/replay path as the current paper boundary and add no
        more observation wrappers at the same caller seam.
  \item Preserve the Week~14 production wrapper and Week~15 fixed all-6 success
        theorem without reproving the rANS loop invariants. Leave fixed-input
        termination/losslessness as separate obligations.
  \item Retain \identifier{STOP-KG-NTT} in the frozen claim matrix as a historical
        boundary. Reuse the NTT/Rq--HAETAE theorems closed post-freeze, without
        retroactively recording them as claims of the frozen PDF.
  \item Resolve the current \identifier{STOP-KG-AVEC-QJ} first. Replace/refine
        synthetic \identifier{public_rounding_vector_seed} with actual ExpandVecA
        semantics, separate it from the paper \(qj\) correction, and prove
        \identifier{OBL-KG-SECURITY-EXPANDVECA-SEMANTICS}.
  \item Connect security \(a\), the actual array, and the Rq/HAETAE row product,
        then transport the mode-2 width-4/mod-\(q\) representation to the paper's
        augmented width-6/mod-\(2q\) matrix, secret, and error packaging. Before
        that, do not claim faithful KG-1/KG-3/full KG-4.
  \item Retain \identifier{STOP-SIGN-CHAL-MODE2}. Do not claim S-1--S-7 without
        the full highbits/LSB/\(\mu\)-to-SampleInBall leaf, application of the
        actual Sign row product, and response/hint representation obligations.
  \item For Verify, close \identifier{verify_matrix_ntt_acc_}\allowbreak
        \identifier{mode2_cols4_correct}, which applies the already closed pure
        NTT foundation to actual 2-by-4 accumulation, and
        \identifier{verify_crt_freeze_mode2_word_exact}; compose the combined
        matrix theorem, then close the downstream challenge leaf.
  \item Keep the (h) codec deferred for now. When its scope is reopened, compose
        size metadata, zero padding, and pack/challenge tail frames to close the
        full 1474-byte codec and canonical parsing.
  \item Combine norm/hint, response, and arithmetic correctness to close
        \claim{OBL-SIGN-OUTPUT-TAIL-REACH} and legitimate Sign/Verify correctness.
  \item In the separate security path, compose public-context \(\mu\),
        highbits/LSB, and the full challenge call.
  \item Quantify KeyGen/Sign distribution and termination losses, then combine
        the byte-faithful ROM scheme with the paper's distribution/forking obligations.
\end{enumerate}

This order advances one step at a time from the nearest already-compiling seam
toward the outer boundary, rather than declaring broad security statements first
and filling their underlying premises afterward.
