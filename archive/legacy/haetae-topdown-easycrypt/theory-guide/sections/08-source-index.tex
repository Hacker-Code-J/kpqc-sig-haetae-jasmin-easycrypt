\section{Notation and abbreviations}

\begin{description}[style=nextline,leftmargin=3.1cm]
  \item[Functional correctness (FC)] The goal that implementation results or
  distributions agree with the paper specification.
  \item[Raw/internal] The internal message path that does not use context-length
  encoding. Verify selects the actual raw branch when \identifier{prelen} is
  less than \(2^{63}\).
  \item[Accepted path] An execution whose actual Verify return value is 0. The
  current theorem proves that this event implies \identifier{tail_reached}, but
  does not claim that arbitrary signatures or legitimate Sign outputs take the accepted path.
  \item[Exact trace] An authored mirror program with the same final memory/return
  value as the actual procedure. Ghost observations are meaningful only when
  actual control flow reaches the corresponding point.
  \item[Region-local] A relation requiring byte equality only on the address
  regions actually read by a procedure, instead of whole-memory equality.
  Differences at other addresses do not affect the result.
  \item[Product/replay boundary] The unresolved semantic edge transporting a
  relational theorem about generated hash returns to stored ghost results of an
  already completed sequential trace. It is currently explicitly \statusdeferred.
  \item[Signature prefix] The first 1056 bytes of a 1474-byte mode-2 signature.
  It contains 32 bytes of challenge bits and 1024 bytes of low coefficients,
  excluding suffix metadata, rANS payloads, and padding.
  \item[HBZ] The layer of \(1024\) high-bit coefficients compressed by rANS in
  the signature suffix. The mode-2 canonical range is \([-6,7)\), and the prepare
  leaf maps it to the 13-symbol alphabet \(0,\ldots,12\).
  \item[rANS step] An arithmetic step reversibly updating the state and symbol
  using a frequency interval. The development covers pure/reciprocal single steps
  and the normalization readback/state-bound traces connecting them; separate
  Week~11/12 theorems connect the actual encoder and decoder outer loops, respectively.
  \item[Normalization-byte stack] The relation in which the decoder consumes
  bytes from the front that the encoder emitted through a backward cursor while
  processing symbols in reverse order. Pure \(xs/cuts/bytes\) semantics and word
  arithmetic are closed. The accumulated outer-suffix bridge, including actual
  encoder inner writes, was closed in Week~11; actual decoder forward consumption
  under exact inputs was closed in Week~12. The edge sequentially composing these
  two theorems with the actual copy call was closed in Week~13.
  \item[Array/list bridge] The Week~10 layer connecting the first 1024 symbols
  of the actual array to a pure list and its suffixes, and providing segment-match
  and frame operations.
  \item[Segment match] The predicate \identifier{segment_matches}, stating that
  a pure byte list is stored pointwise starting at a specified array offset.
  \item[Prefix frame] The predicate \identifier{prefix_frame}, stating that array
  bytes below a specified offset are unchanged across execution.
  \item[Actual inner loop] The normalization loop of generated
  \identifier{_rans_encode}. In addition to the conservative Week~10 \(0..4\)
  phase theorem, the Week~11 tail-aware invariant derives the exact normalization
  length \(0/1/2\) from the actual guard and identifies it with the outer accumulated trace.
  \item[Tail-aware invariant] A verified Week~11 invariant placing both the
  current symbol's normalization bytes and the already existing pure-trace tail
  in \identifier{segment_matches}, restoring the outer one-symbol recurrence
  after the inner loop.
  \item[Exact-trace decoder input] A Week~12 predicate bundling
  \identifier{trace_bytes} computed from canonical 1024 symbols, size, state fields,
  actual decoder tables, and every normalization-byte read into one functional
  representation contract. It includes neither success, output equality, nor
  post-states as premises.
  \item[Partial replay invariant] An inner invariant connecting the number
  \(k\) of bytes already consumed within one decoder-symbol segment, the cursor,
  and the reduced state to \identifier{decoder_replay_prefix}. The actual guard
  equals \(k<|\mathsf{segment}|\), and segment length is 0, 1, or 2.
  \item[Actual rANS harness] A unary composition running actual suffix copy and
  decoder only when the actual encoder return \(bad\) is 0. The existing harness
  theorem proves only branches and decoder input fields. A separate Week~13
  semantic theorem transports the copied segment to exact-trace input, proving
  non-execution on failure and a 1024-symbol round trip on success in the same harness.
  \item[Production full-HBZ harness] The Week~14 harness calling actual
  \identifier{SignaturePackMode2Target.M._encode_hb_z1_full} and, only when the
  returned size is nonzero, actual
  \identifier{SignatureUnpackMode2Target.M._decode_hb_z1_full}. Its results/branch
  flags exactly match the focused full-HBZ harness, and it proves failure
  preservation or 1024-coefficient recovery on success for canonical inputs.
  \item[Fixed all-six success witness] Week~15 Hoare partial correctness that
  arithmetically shows the trace of 1024 occurrences of symbol 6, obtained by
  preparing zero HBZ, fits in a 1024-byte buffer, and excludes zero-size failure
  of a terminating actual encoder by contradiction. It does not mean execution
  existence, termination, or \(\operatorname{phoare}=1\).
  \item[Success-conditioned] A theorem form that explicitly concludes actual
  \(\mathsf{size}=0\) failure or nonzero success, without assuming encoding success
  in a fixed buffer from canonical inputs alone.
  \item[KeyGen snapshot] The Week~16 boundary recording \identifier{pre_bp},
  returned by actual \identifier{_kp_m23_matrix} and retained before the finalizer
  call, together with subsequent actual finalizer low/high and adjusted \(s_2\)
  semantics. It does not call \identifier{pre_bp} the security model's
  \(A_{\mathrm{gen}}s_{\mathrm{gen}}\).
  \item[NTT multiplication bridge] The paper-freeze \identifier{STOP-KG-NTT}
  extended through the final representation rewrite expanding
  \identifier{KeygenM23ArithmeticSpec.output_row} into a full-invNTT/pointwise-word
  expression. Post-freeze work proved odd-root/full-NTT spectral action, the native
  Rq row product, and the Rq--HAETAE coefficient-representation adapter. Security
  ExpandVecA and full mod-\(2q\) packaging do not follow automatically.
  \item[Paper freeze] The fixed boundary at commit \identifier{4bde120}, aligning
  82 authored targets, the claim matrix, theorem graph, reproduction procedures,
  and paper PDF. Later auxiliary theorems do not retroactively extend frozen PDF claims.
  \item[Post-freeze auxiliary layer] Subsequent results verified in the external
  NTT/Rq tree, strengthened existing KeyGen targets, and \sourcepath{post-freeze/}
  without increasing the frozen manifest count. The current verdict is
  \identifier{STOP-KG-AVEC-QJ}.
  \item[MINCORE] The Week~16 minimum paper scope targeting only the paper's core
  KeyGen/Sign/Verify equations and restricted decoded-object composition,
  excluding the full public APIs, codecs, sampler/retry, and termination. KeyGen
  is partial/stopped; Sign is partial/stopped at actual-call control; Verify is
  partial with helper-local word/control results retained; restricted composition
  remains a subsequent specification.
  \item[Generated procedure] An EasyCrypt procedure generated from pinned Jasmin
  sources by \identifier{jasmin2ec}.
  \item[Wrapper] A local module authored for proof alignment. Current central
  theorems place actual generated procedures, rather than wrappers, on the conclusion surface.
  \item[Zero loss] There is no separate statistical-distance term because the
  two executions at the deterministic seam yield exactly the same result.
  It does not mean zero loss for the full API.
  \item[Reachability witness] A theorem showing that a relational theorem's
  premises are consistent and concretely constructed from preceding procedure returns.
  \item[TCB] Trusted computing base. Currently includes EasyCrypt/Why3/provers,
  the Jasmin translator, pinned sources, and host verification tools.
\end{description}

\begin{takeaway}{Current research frontier}
Direct comparison of \identifier{observed_mu} in accepted Sign/Verify traces was
frozen as a paper boundary because there is no product/replay rule transporting
pRHL hash returns to ghost fields of completed traces, not because necessary
premises are missing. On the functional path, after Week~11 actual encoder
successful-suffix refinement, Week~12 directly closed actual decoder initial
parsing, table lookups, 0/1/2-byte replay, and outer/inner loops. A terminating
actual decoder on exact \identifier{trace_bytes} input satisfies \(bad=0\),
exact consumed size, 1024-symbol recovery, and the output-tail frame. Week~13
transported actual encoder \identifier{segment_matches} and copy-helper
\identifier{slice_eq} to those pointwise inputs, closing the actual core inverse
as success-conditioned partial correctness. Week~14 transported full/focused
internal procedure equivalence, the actual full encoder/decoder, and the direct
harness to the production SignaturePack/Unpack boundary, closing the full-HBZ
wrapper inverse at the same strength of partial correctness. Week~15 composed
the all-six trace budget with actual failure causes, transporting nonzero-size
success for fixed zero HBZ to the production boundary. This is a Hoare theorem
about terminating executions, however, not losslessness.

Week~16 composed the two actual M23 matrix/finalizer calls to close snapshot
low/high, adjusted \(s_2\), and the snapshot-only mod-\(2q\) equation. The 77th
manifested target then individually compiled theorems expanding
\identifier{output_row} into the existing full-invNTT/pointwise-word representation
and applying it to the actual snapshot's two active rows. The 82 surfaces,
including restricted Sign/Verify results, are \identifier{PAPER-FROZEN}; their
historical stopping points are \identifier{STOP-KG-NTT},
\identifier{STOP-SIGN-CHAL-MODE2}, and \identifier{STOP-VERIFY-MATRIX-CRT}.

Post-freeze work closed pure NTT spectral action, mathematical KeyGen/Verify row
products, and the Rq--HAETAE representation adapter. Actual mode-2
\identifier{avec} was connected to paper \(a\), and the paper \(qj\) correction
was composed with the snapshot. However, compiled counterexamples confirmed that
the existing security-side synthetic object differs from actual \(a\) and paper
\(qj\), so the current verdict is \identifier{STOP-KG-AVEC-QJ}. The first repair
obligation is \identifier{OBL-KG-SECURITY-}\allowbreak
\identifier{EXPANDVECA-SEMANTICS}, followed by full mod-\(2q\) width-6 packaging.
The pure NTT foundation for Verify is also closed, but actual 2-by-4 accumulation
and CRT/freeze procedure leaves remain. The (h) codec, restricted composition,
termination, context, highbits/LSB, probability distributions, and game-based
security also remain separate obligations. The current frozen-suite 82/82
aggregate and paper-freeze audit are preserved in
\sourcepath{logs/verify-all-summary.txt}.
\end{takeaway}
