\section{Trust boundaries and reproduction}
\label{sec:trust-reproduction}

\subsection{What is trusted}

The trusted computing base (TCB) of this proof development includes the following.

\begin{itemize}
  \item The EasyCrypt kernel/type checker and imported standard libraries;
  \item Why3 and the invoked SMT provers;
  \item The Jasmin parser/compiler and \identifier{jasmin2ec} translator;
  \item Hash-pinned Jasmin sources, generated extractions, and reused EasyCrypt artifacts;
  \item Host tools performing source hashing and LaTeX builds.
\end{itemize}

Acceptance of the source by \identifier{jasmin2ec} and compilation of the
generated EasyCrypt do not prove the translator's semantic preservation. Unless
there is a separate verified-translator theorem, the translator itself remains
in the TCB. Likewise, memory safety and SCT/constant-time properties do not follow
from EUF-CMA and form separate tracks.

\subsection{Proof verification pipeline}

The commands in this historical proof pipeline require the complete earlier
tree restored as described in the archive README. Run them from that restored
repository root.

\begin{verbatim}
./haetae-topdown-easycrypt/scripts/verify-all.sh
./haetae-topdown-easycrypt/scripts/check-paper-freeze.sh
python3 haetae-topdown-easycrypt/post-freeze/check-kg-actual-avec-qj-trace.py
\end{verbatim}

The first command checks the frozen 82-target aggregate, the second explicitly
checks the paper-freeze scope, and the third checks an independent deterministic
witness of the latest post-freeze mismatch.

The script checks the following in order.

\begin{enumerate}
  \item SHA-256 drift in the pinned sources and read-only proof tree;
  \item Regeneration and hash agreement of focused extractions for the packer,
        signature codec, HBZ prepare/apply/full wrappers, API key-copy helpers,
        raw API callers, raw \(\mu\), and transcripts; Week~7 pack/unpack and
        Week~8 focused HBZ procedure-body identity; and identity of generated
        targets reused by the Week~9 actual rANS harness;
  \item Deterministic regeneration of the actual 512-word HBZ symbol certificate,
        generator/output hash agreement, and kernel rechecking of the generated
        EasyCrypt certificate itself;
  \item In addition to Week~9 rANS theorem surfaces, overclaim checks for Week~10
        array/list, word-step, inner-progress, actual inner-loop, serialization,
        and success-size theorem surfaces; Week~11 tail-aware invariants, generated
        word steps, final stores, and actual encoder trace closure; Week~12 decoder
        cursor/table/replay invariants and actual trace refinement; Week~13 copy
        traces, pointwise inputs, W64 size adapters, and the actual core inverse;
        Week~14 full/focused internal equivalence, full encoder/decoder, direct
        harness, and production-boundary lift; Week~15 fixed all-six budget,
        failure causes, and production success lift; and frozen-surface checks for
        Week~16 actual M23 matrix/finalizer snapshots, the final NTT representation
        rewrite, direct Sign/Verify core control, and \identifier{STOP-VERIFY-MATRIX-CRT};
  \item Fresh \identifier{-no-eco} compilation of the 82 currently manifested
        authored EasyCrypt targets;
  \item Absence of \identifier{admit}, \identifier{sorry}, authored
        \identifier{axiom}s, and debug/temporary declarations, and manifest completeness;
  \item Fresh compilation of selected upstream baselines;
  \item Builds of the existing sprint LaTeX research notes without reference/citation errors;
  \item A paper-freeze audit checking that the frozen PDF, 82 targets, claim matrix,
        and exact blockers in \sourcepath{manifests/paper-artifacts.md} remain unchanged.
\end{enumerate}

\subsection{Building this document}

This guide is a XeLaTeX document independent of the existing sprint notes.
To build the English edition, run the following in this archived guide's
directory, using the fonts listed in its README:
\begin{verbatim}
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
\end{verbatim}
This builds the translated PDF only. The original build script below requires
the complete earlier tree. From that restored repository root, run

\begin{verbatim}
sh haetae-topdown-easycrypt/theory-guide/build.sh
\end{verbatim}

to generate \sourcepath{haetae-topdown-easycrypt/theory-guide/main.pdf}.
The script treats fatal errors and undefined references/citations as failures.

The tool versions observed when writing this document were
Jasmin/\identifier{jasmin2ec} 2026.03.0, EasyCrypt OPAM switch
\identifier{easycrypt-5.2}, and Why3 1.8.0; configured provers included
Alt-Ergo 2.6.0, CVC4 1.8.0, CVC5 1.2.1, and Z3 4.12.6.
For exact reproduction results, execution logs take precedence over version strings.

\begin{takeaway}{Completion criteria}
The following criteria concern updates to the historical research baseline;
the English edition does not claim a new proof replay.
Compilation of this guide and compilation of EasyCrypt theorems are different
forms of evidence. Before distributing the document, both \identifier{build.sh}
and the full \identifier{verify-all.sh} must succeed. The current frozen proof
baseline is the terminal PASS of the 82/82 aggregate and paper-freeze audit.
Post-freeze claims additionally require separate checks of fresh compilation of
the three actual-\identifier{avec}/paper-\identifier{qj} targets, the Rq/NTT
auxiliary targets, and the deterministic trace. Intermediate PASS lines in a
summary being overwritten are not completion evidence. The separate build of
this guide must also be checked.
\end{takeaway}
