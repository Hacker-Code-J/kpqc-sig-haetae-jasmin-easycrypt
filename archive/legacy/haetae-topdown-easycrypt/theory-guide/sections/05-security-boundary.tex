\subsection{The meaning of local zero loss}

\cref{thm:challenge-suffix} uses neither an approximation between probability
distributions nor a random-oracle idealization. It is a relational equivalence
stating that two deterministic generated procedures return the same state under
the same premises. Thus, for this particular seam only, we may record
\[
  \delta_{\mu,\mathrm{raw\_top}}=0
\]
as an equality.

\begin{boundary}[Equalities that cannot be promoted]
\label{bdry:no-promotion}
The local equality implies none of
\[
  \delta_{\mathrm{Sign}}=0,
  \qquad
  \delta_{\mathrm{Verify}}=0,
  \qquad
  \delta_{\mathrm{Encoding}}=0
\]
these equalities. The verification script fails if strings expressing such
unjustified promotions appear in the authored tree.
\end{boundary}

Although the name of \cref{thm:accepted-api-adapter} contains
\identifier{zero_loss}, it does not currently justify an API equality. The
cross-call frame, region-local hash relation, and exact sequential trace now
compile, but there is no product/replay conclusion transporting the generated
hash return value to the stored observation in the completed trace. Therefore,
\[
  \delta_{\mu,\mathrm{raw\_api\_accept}}=0
\]
is not yet recorded.

This distinction is essential to avoid understating the loss terms in
\cref{eq:implementation-bound}. The current theorem only makes one deterministic
part inside \(\delta_{\mathrm{Sign}}\) and \(\delta_{\mathrm{Verify}}\) zero;
it does not close the entire hybrid, which includes the sampler, rejection,
packing, parsing, public context, and API memory. However, many subsidiary API
memory boundaries---address round trips, sequential KeyGen export, Sign traces
and output frames, accepted Verify tails and input binding, and region-local
hash read relations---are now closed by actual caller theorems.

The HBZ leaves/tables/single steps, pure byte stack, actual suffix copy and harness
control, and actual encoder inner byte/frame steps and successful-size bounds
from Weeks~8--10 are also deterministic functional-correctness evidence.
Week~11 closed the full actual encoder successful-suffix equality with the same
kind of evidence. Week~12 also closed actual decoder exact-trace recovery as
deterministic partial correctness under an exact input relation. Week~13 closed
the sequential composition of the three actual procedures as success-conditioned
partial correctness. Week~14 closed the direct full-HBZ harness including actual
prepare/apply, and its exact equivalence at the production SignaturePack/Unpack
boundary. Week~15 excluded zero-size failure in terminating production executions
on a fixed all-zero input. However, termination and losslessness for that fixed
input, success on general canonical inputs, the (h) codec, metadata/padding, and
full parsing remain open, so these results cannot be promoted to
\(\delta_{\mathrm{Encoding}}=0\).

The Week~16 KeyGen snapshot theorem is also deterministic
functional-correctness evidence, but does not mean
\(\delta_{\mathrm{KeyGen}}=0\). The final rewrite expanding the actual matrix
helper's \identifier{output_row} into a full-invNTT/pointwise-word expression and
the two active-row consequences for the actual harness compiled as the 77th
target. At this 82-target paper boundary, odd-root/full-NTT convolution and the
\identifier{Rq.poly}-to-security-list adapter were missing, so the boundary was
frozen at \identifier{STOP-KG-NTT}. Sign actual-call control, V-1/V-2/V-5/V-6 for
canonical decoded \((x,v,h,c)\), the W64 norm gate, and the tail/mismatch word
expressions also appear in the frozen claim matrix, but the matrix/CRT and
challenge blockers remain open.

The post-freeze auxiliary proofs closed pure NTT spectral action, the native Rq
row product, and Rq--HAETAE representation preservation, interpreted terminating
actual \identifier{avec} executions as the paper's \(a\), and composed the
snapshot with a separate paper-\(qj\) term. However, coefficient~0 of the existing
security-side object is 401, the paper's \(qj\) is 64513, and the first
coefficient of the actual all-zero-seed trace is 44985. This mismatch is fixed by
the compiled \identifier{security_named_qj_is_not_paper_qj}. Thus the current
auxiliary frontier is \identifier{STOP-KG-AVEC-QJ}; the sampler, retry, packer,
public API, distribution/termination, and final KG equation remain outside it.

\subsection{Distinguishing assumptions, contracts, and proof obligations}

The only cryptographic assumptions that may remain in the final security theorem
are the concrete HAETAE-2 MLWE, BST-MSIS, and ROM games. In contrast, the following
items must not be hidden as cryptographic assumptions.

\begin{itemize}
  \item Validity, sizes, separation, and aliasing conditions of public buffers;
  \item Canonical lengths and mode-2 constants;
  \item Retry termination/losslessness and RNG/random-tape interpretation;
  \item FIPS202 byte transcripts, padding, domain separation, and endianness;
  \item The hyperball sampler and accepted-signature distribution;
  \item FFT fixed-point errors and the tied-minimum policy.
\end{itemize}

These are contracts to be proved in API refinement, probabilistic programming,
and numerical analysis, respectively. The current authored theories do not cover
these gaps with new \identifier{axiom}s or proof holes.
