\section{Scope and Proof Architecture}

This paper covers HAETAE mode 2 only. The official specification source is the
pinned PDF artifact \cite{haetae-pdf}. The implementation target is the pinned
Jasmin source tree \cite{haetae-jasmin}. Existing EasyCrypt artifacts are
reused only through explicit imports with premise preservation
\cite{haetae-ref-easycrypt}.

The frozen objective is to report the strongest fresh-compiled refinement
slices for actual extracted procedures and to identify, mechanically and by
name, the semantic leaves that prevent full algorithm composition.  It is not
to claim complete functional correctness or implementation EUF--CMA security.
One checked composition seam used in this workspace is:
\[
\prefix_{992}(sk) = vk
\Rightarrow \mathsf{equal\_hash\_inputs}
\Rightarrow \take_{32}(\mu_{\mathsf{sign}}^{64}) = \mu_{\mathsf{verify}}^{32}
\Rightarrow \mathsf{equal\_challenge\_suffix}.
\]

The Week 1 and Week 2 seams are intentionally narrower than full API
correctness. The work records exact theorem statements, premises, and blocked
obligations instead of hiding them behind new axioms.
