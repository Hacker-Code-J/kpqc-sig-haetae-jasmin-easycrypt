\subsection{Compiled theorem and premises}

Theory \path{RawApiSignOutputFrame.ec} opens the generated
\procname{_api_copy_2948_to_raw}. Lemma
\theoryname{sign_output_copy_exact_and_frames_reused} proves exact publication
of 1474 bytes and a byte frame outside the destination interval. It is then
composed with the actual 8-byte \texttt{siglenu} store.

The actual caller theorem is
\theoryname{sign_raw_api_frames_reused_regions}. Its premises are:
\begin{itemize}
  \item the initial memory and concrete raw ABI arguments;
  \item a valid, non-wrapping 1474-byte signature output region;
  \item disjointness of signature and siglen writes from VK(992), SK(1408),
        pre, and message regions; and
  \item disjointness of the signature and siglen output regions.
\end{itemize}
For every terminating execution it concludes success, stability of all four
reused regions, and the value 1474 at \texttt{siglenu}. This is Hoare partial
correctness: it does not prove termination of the signing rejection loop.

\subsection{Invariant, transfer, and non-vacuity}

The copy-loop invariant records exact bytes already written and a frame for
all addresses outside the full output interval. The subsequent \texttt{W64}
store is handled bytewise and composed by transitivity. Exact equivalence
\theoryname{sign_raw_api_exact_mu_trace} transfers the trace result to the
actual \procname{cryptolab_haetae_mode2_signature_internal} procedure while
preserving result and final memory.

The earlier attempt to name the procedure-local \texttt{sigp} array directly
after a sequence cut failed because that local was outside the theorem
instantiation scope. The replacement is a source-independent frame lemma for
the generated copy; exact copied bytes remain in the separate copy theorem.
