is the compiled accepted-path adapter from actual caller observations to the
generated hash-call theorem.  It reuses:

\begin{itemize}

  \item the actual accepted Verify trace observations;
  \item the imported-prefix and external-key-prefix premises; and
  \item the canonical raw/pre-message region premises.
\end{itemize}

\[
  \mathsf{mu32\_prefix}(\mathsf{res}_1,\mathsf{res}_2),

procedures.  The theorem does \emph{not} claim equality of the two trace
modules' stored \texttt{observed\_mu} fields.  That direct equality remains
open, and the report therefore does not record
\(\delta_{\mu,\mathrm{raw\_api\_accept}} = 0\).
