correctness proof.  The Week~4 question is whether external buffers used by
the three raw/internal ABI procedures supply the memory premise of the already
proved generated mu theorem without constructing an artificial

\subsection{The int/word boundary}

\claimid{OBL-API-ADDRESS-BINDING} uses the definitions
\[
\begin{aligned}
  \mathsf{canonical\_ui64\_address}(a)
    &\eqdef 0 \leq a < 2^{64}, \\
  \mathsf{canonical\_region}(a,n)
    &\eqdef 0 \leq a \land 0 \leq n \land a+n \leq 2^{64}.
\end{aligned}
\]
The central compiled statement is
\[
  \mathsf{canonical\_ui64\_address}(a)
  \Longrightarrow
  \operatorname{to\_uint}(\operatorname{of\_int}(a))=a.
\]
Theorems
\theoryname{canonical_region_valid_region_int} and
\theoryname{canonical_region_valid_region_w64} transport one region contract
to the two generated calling conventions.  The mode-2 specializations fix
$n\in\{992,1408,1474\}$.  All premises are explicit: modular reduction is not
silently ignored outside the canonical range.  The claim is \status{proved},
while actual C/Jasmin allocation and memory safety remain runtime contracts.

\subsection{Non-vacuity}

The earlier adjacent-region witness provides disjoint valid VK and SK ranges,
the new address bridge gives concrete canonical instances, and
\theoryname{stable_region_refl} proves that the stability contract has a
model.  These witnesses show satisfiability only; they do not replace actual
caller reachability.
